# Changelog

What changed in each version of Plumo, for the people who use it. Each version has a
section, newest first, with its changes under Added, Improved and Fixed. The section of a
version is also its release notes on GitHub and what the Update popover shows, so every
line says something a user can notice. `docs/releasing.md` says how a version is cut.

## 0.1.0

The first release of Plumo, for Apple Silicon Macs on macOS 13 or later. Nothing has changed since 0.1.0-beta.1.

### Added

- Open a Folder and browse its Documents and images from the sidebar, or open a single `.md` file on its own.
- Edit in Rich mode, or switch to Raw mode to see the exact Markdown on disk.
- Changes save themselves as you type. If a save is refused, Plumo keeps your edits and asks what to do.
- Tabs for open Documents and images, with Pinned files and recent Folders in the sidebar.
- Quick Open and the Command Menu find a file or run any menu command from the keyboard.
- Tables, images with captions and widths, code blocks, math, Mermaid diagrams, callouts and whiteboards.
- An Outline of the Document's headings, and Sections that fold.
- Light and dark themes, and a choice of primary color.
- Plumo updates itself: a new version downloads in the background, and an Update button appears when it is ready.
